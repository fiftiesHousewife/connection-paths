# The calls that open, or use, a connection to something outside the program.
# One rule a line: <kind> <type>#<method>. A method of * means every method but the constructor.
# A rule matches a call to that type or to any type that extends or implements it; a rule naming the exact type wins
# over one that matches through a supertype. Lines starting with # are comments.
# A rule <kind> @<annotation> matches a call to a method carrying the annotation, or declared in a type that carries
# it: clients that are only an interface, made at run time by a library.
